## 개인정보처리방침

**리버스레시피** (이하 "앱")는 [개발자 실명] (이하 "개발자")이 개인 개발자로 운영합니다.
이 방침은 앱이 수집하는 정보, 사용 방식, 이용자의 권리를 설명합니다.

### 1. 수집하는 정보

#### 1-1. 이용자가 직접 입력하는 정보
| 항목 | 목적 |
|------|------|
| 냉장고 재료 목록 | 레시피 추천 기능 제공 |
| 소비기한 정보 | 임박 재료 우선 추천 |

| 계정 생성 시 이메일·비밀번호 | 인증 및 데이터 동기화 |

#### 1-2. 자동 수집 정보 (Google AdMob)
앱은 **Google AdMob SDK**를 사용하여 맞춤형 광고를 표시합니다.
AdMob은 아래 정보를 자동으로 수집할 수 있습니다.

- **광고 ID (Advertising ID / GAID)**: Android 기기별 재설정 가능한 식별자
- 대략적인 위치 (국가 수준)
- 기기 정보 (OS 버전, 기기 유형)
- 앱 사용 이벤트 (광고 노출, 클릭)

> Google의 데이터 처리 방침: https://policies.google.com/technologies/ads

#### 1-3. 서버 로그
서버는 오류 진단을 위해 요청 타임스탬프와 HTTP 상태 코드를 기록합니다.
IP 주소는 기록하지 않습니다. (미확인 — 호스팅 결정 후 확인 필요)

### 4. 광고 ID 및 맞춤광고

#### 4-1. 광고 ID란
Android 기기에 부여되는 재설정 가능한 식별자입니다.
AdMob은 이를 사용해 이용자 관심사에 맞는 광고를 표시합니다.

#### 4-2. 맞춤광고 거부 방법

**Android 12 이상**
1. 기기 설정 > 개인정보 보호 > 광고
2. "광고 개인 최적화 해제" 선택
   또는
3. "광고 ID 삭제"를 선택하면 AdMob이 기기를 더 이상 추적하지 못합니다.

**Android 11 이하**
1. Google 설정 앱 > 광고
2. "광고 개인 최적화 해제" 선택

맞춤광고를 거부해도 광고는 계속 표시되나, 관심사 기반이 아닌 일반 광고가 표시됩니다.

#### 4-3. UMP (동의 관리 플랫폼)
EEA/영국 이용자에게는 앱 첫 실행 시 Google UMP SDK를 통해
GDPR 동의 화면이 표시됩니다. (B-013 구현 완료 후 적용 예정)

### 6. 보안

이용자 데이터는 HTTPS로 전송됩니다.
비밀번호는 bcrypt로 해시 처리됩니다.
서버는 현재 JWT를 클라이언트 스토리지에 보관하며, httpOnly 쿠키 방식으로의 전환을 계획 중입니다.
