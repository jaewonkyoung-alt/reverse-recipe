소비시켜 음식물 낭비를 줄이는 앱.
루트: `/Users/kyoungjaewon/AI결과물/리버스레시피_클로드/`

## 기준 문서 (충돌 시 이 순서로 우선)
1. `DECISIONS.md` — 사람이 내린 결정. 절대 뒤집지 마라.
2. `REBUILD_PLAN.md` — 아키텍처·알고리즘 설계 기준
3. `RELEASE.md` — 출시 준비 상태
4. `BACKLOG.md` — 작업 큐
5. `EVAL.md` — 평가 이력

## 증거 규칙
- 실제로 하지 않은 일을 했다고 쓰지 마라.
- "수정함 / 통과함 / 업로드함"은 근거를 함께 제시할 때만 쓴다.
- 근거가 없으면 "초안 작성함(미적용)" / "미검증" / "사람 확인 필요"로 적는다.
- 테스트를 실행하지 않았으면 절대 "통과"라고 쓰지 마라.

## 에스컬레이션
사람만 할 수 있는 일(계정, 결제, 법적 동의, 실제 업로드, 방향 결정)은
직접 하려 들지 말고 `DECISIONS.md`에 아래 형식으로 추가한다.

```
## [대기] <제목>
- 필요한 결정: <무엇을>
- 선택지: <A / B / C와 각 트레이드오프>
- 권고: <하나> — <이유 한 줄>
- 차단 중인 작업: <이게 막고 있는 것>
```
